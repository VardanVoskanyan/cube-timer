# Cube Timer

A small static Rubik's cube timer — no build step, no dependencies.

- Random 20-move scramble, drawn on an unfolded cube
- Hold <kbd>Space</kbd> until green, release to start, <kbd>Space</kbd> to stop (<kbd>Esc</kbd> cancels); tap/hold the timer on touch devices
- Times list, statistics (best, worst, mean, median, std., Avg. 5 / 3 of 5, Avg. 12 / 10 of 12 and their bests), progress graph and histogram
- Solves are stored in the browser's `localStorage`; use **Export** / **Import** for a JSON backup

## Run locally

Open `index.html` in a browser.
